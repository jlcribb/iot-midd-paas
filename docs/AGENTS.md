# AGENTS.md — Documentation

## Objetivo

Mantener documentación coherente con el sistema.

## Responsabilidades

- documentar contratos
- documentar arquitectura
- documentar decisiones

## Reglas

R1 Toda decisión técnica relevante debe documentarse  
R2 No dejar features sin documentación  
R3 Mantener sincronía con código  

## Prohibido

NO documentar features inexistentes  
NO dejar documentación obsoleta  

## Definition of Done

✔ documentación actualizada  
✔ consistente con código  
✔ clara para desarrolladores

# Legacy Scope

Este directorio agrupa documentacion historica o piezas que ya no describen la arquitectura oficial del sistema.

Clasificacion actual:

- API Python historica: legacy
- CRUD historico del admin: legacy
- documentacion raiz previa enfocada en particiones/CRUD como centro del producto: legacy o historica

La regla es simple:

- lo que describe el runtime oficial queda en `README.md`, `docs/architecture/` o `docs/operations/`;
- lo que describe estados previos, enfoques superados o componentes a retirar se mueve progresivamente aqui.
